# 使用指南与统计定义

## 登录与导航

打开部署方提供的站点地址，以 viewer 访问令牌登录。节点上报令牌不能用于网页登录。页面不提供主机控制、终止进程、用户管理或远端命令执行能力。

导航顺序为运行概览 → 使用率统计 → 服务器 → 进程与用户。支持即时锚点跳转、键盘、前进 / 后退和带锚点链接；首次鉴权完成后定位目标，后续刷新不改变当前位置。高亮随滚动和布局更新，移动端为顶部导航预留空间。

浏览器约每 5 秒读取中心。暂停仅关闭页面自动刷新，不停止节点采集；仍可手动刷新。网络中断保留最后一次显示并提示错误，恢复后继续更新。中心启动后等待新报告，不把历史缓存当作在线证明。

## 服务器、详情与置顶

服务器列表支持名称、地址、GPU 型号和状态过滤。节点卡片与详情显示实际读到的设备，不从名称推算 GPU 数量。磁盘 ≥90%、内存 ≥95%、GPU 温度 ≥85°C 或 GPU 读取错误提示需关注；GPU 高负载本身不是故障。

图钉将节点放入概览上方的“重点关注”，可置顶多台并按选择顺序展示。顶部卡片不受列表过滤影响，与完整列表共享实时数据，不重复计入汇总；详情窗口也能切换置顶。离线 / 待上报节点保留置顶位置但清除旧指标，配置中已移除的节点不继续显示。

置顶偏好是同源浏览器本地数据，不跨设备共享；存储被禁止时仍可在当前标签页使用，但无法持久保存。

DCGM 数据源节点在卡片标注来源；详情可额外显示受硬件 / 权限支持的 SM / Tensor / DRAM 活跃度、PCIe / NVLink 速率、显存温度、时钟、volatile ECC 累计计数与最近 XID。缺失显示 `—`，不是零；这些是当前快照，不是新增历史统计。默认仍优先 NVIDIA-SMI，具体配置及口径见 [GPU 数据源](gpu-metrics.md)。

## 进程与用户

表格显示 GPU 进程关联，支持全局搜索和用户筛选后分页，每页 25 / 50 / 100 条。独立进程按 `host:pid` 去重；一个进程使用多张 GPU 时会有多条关联，页脚同时显示两种数量。

改变筛选或每页条数回到第一页；刷新保留当前页，数据减少时收缩到合法页码。无结果显示 `0 / 0`。表格随页面纵向滚动，窄屏可横向滚动。

采集的是 NVIDIA 提供的名称 / 路径、PID、用户、类型和显存，不读取完整命令行，也不把整卡使用率分摊为进程使用率。权限、MIG / MPS 或容器 PID 限制可能导致未知值；应用不自动提权或猜测。进程用户仅保留最新快照，不提供历史用户账单。DCGM exporter 不提供等价逐进程列表；可显式使用 NVIDIA-SMI 按 UUID 补充，禁用或读取失败时页面提示未知 / 部分覆盖，而非断言零进程、零用户。

## 外观与站点品牌

右上角调色盘面板提供自动 / 浅色 / 深色，以及绿、蓝、紫、琥珀、青、玫瑰六种配色。支持 Enter / 向下键展开，Esc 关闭并恢复焦点，外部点击或 Tab 移出关闭。

站点可配置标题、品牌、图标、工作区、页脚与默认外观，见[UI 配置](configuration.md#3-ui-配置)。首次访问使用站点默认；用户保存的有效主题 / 配色优先，自动主题跟随系统。损坏或不可读的偏好回落到站点默认，首次绘制前即可生效。

外观切换不改变登录、置顶、筛选、图表数据或进程页码。控件、图表、弹窗和浏览器主题色同步适配；字母 favicon 随配色变化，自定义 PNG 保持不变。长品牌名称截断展示，完整名称保留于侧栏链接提示。

## 采样、在线与历史

| 概念 | 定义 |
| --- | --- |
| 采样周期 | 配置的目标间隔；实际还包含采集耗时与部署调度抖动 |
| 离线 | 超过 stale_after 没有有效报告；不等于已确认关机 |
| 最后成功时间 | 最近成功采集 / 上报的时间，失败时保留 |
| 缺失指标 | 未知 / NULL，不当作 0% |
| 历史时间 | 中心接收报告时间 |

中心校验身份、UUID、指标范围、有限数值、采样周期和时钟，请求体上限 1 MiB。采样时间须在 `max(60, 2 × interval)` 秒允许范围内；重复不增加历史或延长存活，乱序及不合理时间被拒绝。节点与中心需 NTP / chrony 同步，应用不调整系统时间。

离线 / 待上报时清除实时指标，新有效报告恢复状态。历史仅从有效上报起累积，缺口不填充、不延长为连续在线；图表保留断线。演示与真实数据库禁止共用。

历史保留期由配置决定，默认 30 天，每小时清理过期数据。清理不缩小 SQLite 文件，空闲页可复用。在线备份使用 SQLite backup API；文件复制需先停服并正确处理 WAL，不能遗漏已提交数据。

## 统计定义

- **GPU 均值**：按有效 GPU 卡样本加权，缺失利用率不进入分母。
- **显存使用率**：有效显存用量之和 / 有效显存容量之和，不简单平均不同容量卡的百分比。
- **CPU / 系统内存均值**：按节点有效样本平均。
- **图表**：约 180 个平均桶；峰值从原始样本计算，不是聚合曲线峰值。
- **繁忙 GPU 卡时**：使用率 ≥10% 的卡数 × 有效样本时长 / 3600。每个样本最多代表自身采集周期，并在下一样本或查询结束处截断。
- **观测在线率**：成功样本有效时长 / 已观测有效时长。
- **采集覆盖率**：有效时长 / 查询时长；集群分母乘以节点数。

低覆盖率下的高在线率不能代表完整观测。这些是样本统计，不是精确连续积分或用户计费。查询范围最长 31 天，CSV 使用当前时间与节点条件。

CPU、网络和块 I/O 使用约 250ms 差分；内存采用 MemAvailable；磁盘口径包含文件系统保留块。网络排除回环及常见容器接口，块 I/O 避免重复计算分区 / device-mapper。

## 存储与安全

| 浏览器存储 | 内容 |
| --- | --- |
| `localStorage["hqlab-monitor-token"]` | 持久保存的 viewer 令牌 |
| `localStorage["hqlab-monitor-auth-revision"]` | 无秘密的登录状态变更标记，不是会话 ID |
| `localStorage["hqlab-monitor-pinned-hosts"]` | 置顶节点名 |
| `localStorage["hqlab-monitor-appearance"]` | 明暗 / 配色偏好 |

登录验证成功后，viewer 令牌保存在 localStorage，关闭标签页或重启浏览器后仍可使用。同一来源的标签页共享登录 / 退出状态；来源包括协议、主机和端口，换地址后需重新登录。旧 sessionStorage 中的令牌会在验证成功后尝试一次迁移，迁移前遇到网络错误不会丢弃。普通轮询不重新保存令牌；迟到响应与排队中的 storage 事件不能撤销已经观察到的新登录 / 退出。退出即使没有持久令牌也会留下无秘密的变更标记，阻止其他标签页的旧会话再次迁移。浏览器禁止持久存储时会退回当前会话，登录时提示无法持久保存；会话回退同时记录变更标记，存储恢复后可在重载时重新验证迁移。

右上角“退出登录”会清除本地和旧会话令牌并重新加载页面，保留外观与置顶。API 返回 401 时清除失效令牌；网络错误或服务端暂时失败不清除。清除站点数据也会清除登录与偏好。

令牌只通过 Authorization 传输，不写 URL 或 cookie。localStorage 可被同源 JavaScript 读取，同一浏览器配置的使用者也可能继续访问，适合可信内网的简单访问限制；共享设备使用后应退出，非可信网络仍需 HTTPS 和更完整的访问控制。页面未单独提供密码管理器保存功能。

页面、图标和品牌在鉴权前公开，不应配置敏感信息。真实指标需要 viewer 鉴权；节点上报令牌彼此隔离。HTTP 仅适用于可信内网，其他网络需要部署方提供 HTTPS、访问限制和防火墙。
