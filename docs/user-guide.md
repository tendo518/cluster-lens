# 页面、采样与统计说明

## 页面导航与刷新

工作空间顺序与页面一致：运行概览 → 使用率统计 → 服务器 → 进程与用户。使用原生即时锚点跳转，支持键盘、浏览器前进 / 后退、带锚点链接以及首次登录加载后的定位；手机端为顶部导航预留空间。高亮随滚动、筛选、置顶及窗口尺寸变化更新，后续数据刷新不会把页面拉回旧锚点。

浏览器约每 5 秒读取中心；暂停的是页面自动刷新，不暂停节点采集。可手动刷新；网络中断保留最后一次显示并提示连接错误，恢复后更新。中心刚启动时等待新的报告，不把历史缓存直接显示成在线。

## 服务器与进程

服务器列表可按名称、地址、GPU 型号和状态过滤。节点卡片展示真实读取到的 GPU 数量，不从节点名推算；点击卡片名称或 GPU 打开详情。磁盘 ≥90%、内存 ≥95%、GPU 温度 ≥85°C 或 GPU 读取错误会提示需关注；GPU 高负载本身不是故障。

进程表默认每页 25 条 GPU 关联，可切换为 50 / 100 条，支持首页、上一页、下一页和末页。页脚分别显示匹配的独立进程数、GPU 关联数和当前条目范围；同一进程使用多张卡时按多条关联展示，独立进程按 `host:pid` 去重。

搜索和用户筛选作用于全部记录，再分页。改变筛选或每页条数回到第一页；自动刷新保留当前页，记录减少时将页码收缩到合法范围。无匹配记录显示 `0 / 0` 并禁用翻页。进程表没有独立纵向滚动区，手机端保留横向滚动。

进程只采 NVIDIA 报告的名称 / 路径、PID、用户、类型、显存，不采完整命令行参数，不将整卡 GPU 使用率伪造为各进程使用率。用户不可读、MIG / MPS 或容器 PID 等限制会产生未知值，不自动提权或猜测。进程用户只保留最新快照，不提供历史用户计费或作业账单。

## 置顶重点服务器

点击卡片右上角图钉，可把节点放到集群汇总之前的“重点关注”区域。支持多台、按置顶顺序展示；再次点击取消，详情窗口也可操作。顶部卡片与完整列表使用同一份实时数据，不受列表筛选影响，不重复计入汇总。

节点离线 / 待上报时仍保留置顶位置，但清除旧 GPU 和资源指标。已不在配置清单中的节点不会继续显示。键盘操作、刷新、筛选和详情更新均保留合理的焦点。

偏好保存在当前站点 `localStorage["hqlab-monitor-pinned-hosts"]`，仅有节点名、不含令牌；同源标签页同步，不跨浏览器 / 设备共享。清除站点存储会清除选择；存储被禁止时仍可在当前标签页使用，并提示无法持久保存。

## 明暗与配色

右上角调色盘图标打开下拉面板，选择自动 / 浅色 / 深色，以及绿色、蓝色、紫色、琥珀色、青色、玫瑰色。默认绿色、跟随系统；手动主题优先于系统偏好。支持 Enter / 向下键展开、Esc 关闭并返回图标、再次点击或点击外部 / Tab 移出关闭。

切换不丢失登录、置顶、过滤、图表数据或进程页码。偏好存于 `localStorage["hqlab-monitor-appearance"]`，同源标签页同步，首次绘制前恢复。无法保存时仅在本标签页生效。原生控件、图表、提示框、弹窗、浏览器主题色与 favicon 同步适配。

页面使用自定义低饱和配色，不依赖 UI 组件库。正文及指标保持可读字号；窄屏 GPU 每行最多四列，显存单独显示，避免数值挤压。

## 在线状态与历史

- 节点按配置周期采集上报，实际间隔还包含执行耗时及部署 timer 的抖动；不能将没有采样的时间假定为持续在线。
- 默认 100 秒无有效报告标记离线；离线不等于已确认断电。离线清除实时指标，保留最后成功时间，收到新报告后恢复。
- 中心验证 UUID、指标范围 / 有限数值、周期、身份和时钟。请求体最大 1 MiB，拒绝乱序与不合理时间；重复报告不会增加历史或延长存活时间。
- 历史使用中心接收时间；报告采样时间须位于 `max(60, 2 × interval)` 秒允许范围内。节点与中心应通过 NTP / chrony 保持同步，应用不改系统时钟、不放宽校验掩盖故障。
- 历史从有效上报后累积，缺失 / 离线存 `NULL`，不记为 0%，图表断线，不填补停采区间。演示和真实数据库禁止共用。
- 默认历史保留 30 天，每小时清理过期数据。自动清理不压缩 SQLite 文件，空闲页可复用；备份应使用 SQLite backup API，或停服后复制完整数据库，不能忽略 WAL。

## 统计定义

- **GPU 均值**：按有效 GPU 卡样本加权；缺失利用率不计入分母。
- **显存使用率**：有效显存用量之和 / 有效显存容量之和，不简单平均不同容量卡的百分比。
- **CPU / 系统内存均值**：按节点有效样本平均。
- **图表**：聚合为约 180 个平均桶；峰值从原始样本计算，不是聚合曲线的峰值。
- **繁忙 GPU 卡时**：利用率 ≥10% 的卡数 × 有效样本时长 / 3600。每个样本最多代表自身采集周期，并在下一样本 / 查询结束处截断，长缺口不延长计时。
- **观测在线率**：成功样本有效时长 / 已观测有效时长。
- **采集覆盖率**：有效时长 / 全部查询时长，集群口径乘以节点数。必须结合在线率判断，不能把低覆盖率的高在线率当成完整可靠观测。

这些是样本统计，不是精确连续积分，也不是用户账单。自定义历史范围最长 31 天；CSV 导出使用当前统计时间范围与节点条件。

CPU、网络和块 I/O 使用约 250ms 差分；内存使用 `MemAvailable`；磁盘与 `df` 的保留块口径一致。网络排除回环及常见容器接口，块设备避免重复计算分区 / device-mapper。

## 登录与安全

viewer 令牌和逐节点 agent 令牌相互独立，通过 `Authorization` 传递，不进入 URL。viewer 令牌仅保存在当前标签页 `sessionStorage["hqlab-monitor-token"]`，不写入 localStorage、cookie，也没有实现密码管理器保存功能。

公开 HTTP 只适合可信内网；其他网络应由部署方配置 HTTPS、访问限制和防火墙。应用不提供主机管理、杀进程、修改时钟或账户管理操作。配置、令牌和独立 agent 的完整接口见 [配置契约](configuration.md)。
